## 1. 状态定义

| 状态 | 定义 |
|---|---|
| 已确认 | 需求或技术决策已经形成书面基线 |
| 已设计 | 已形成接口、架构或状态机设计 |
| 已实现 | 代码已存在并通过编译或类型检查 |
| 已验证 | 已执行明确用例并保留可追溯结果 |
| 待验证 | 已设计或已实现，但尚无对应真实环境证据 |
| 阻塞 | 缺少样板、SDK、参数或正式资料 |

“已实现”不得等同于“已验证”。虚拟HAL验证不得替代板级电平验证，服务接口连通不得替代专项质量测试。
