## 1. 交付范围

本批文件用于说明DX-AI-01样板前阶段已经形成的软件设计、接口基线、固件构建状态和已有验证证据，同时列明尚未验证及受外部输入阻塞的项目。

本批文件不是产品定型报告、量产验收报告、真实负载测试报告或AI准确率报告。

## 2. 建议审阅顺序

1. 《项目范围与技术决策基线 V1.0》：确认产品边界和已经采用的技术路线；
2. 《C3单主控系统架构与职责边界 V1.0》：确认ESP32-C3、CI1302、平台和本地控制终端的职责；
3. 《DX-AI-01 Rev.A硬件设计输入书 V1.0》：作为东信首板设计输入；
4. 《ESP32-C3固件软件设计说明 V1.0》：评审C3软件分层、启动、控制、安全和外设接口；
5. 《在线AI语音链路技术设计说明 V1.0》：评审在线ASR、规则路由、LLM、安全校验和TTS链路；
6. 《需求-设计-实现-验证追踪矩阵 V0.4》：逐项确认当前状态；
7. 《阶段技术状态与验证记录 V0.4》：核对已经执行并有证据的验证；
8. 《待确认参数及后续验证项 V0.4》：确认下一阶段输入、责任和Gate；
9. 《AI语音专项测试计划与数据集规范 V1.0》：开展ASR、LLM、知识库和TTS专项。

## 8. 交付完整性检查

交付前应确认：

- 文件版本、日期和适用产品一致；
- “已设计”“已实现”“已验证”“待验证”“阻塞”未混用；
- 每项已验证结论均能追溯至命令、日志、任务ID或构建产物；
- API Key、WiFi密码、设备密钥和生产凭证未进入交付包；
- 原始音频及测试产物未提交公共源码仓库；
- 大文件、厂商受限资料和构建缓存未进入Git；
- 尚未验证的指标没有准确率、SLA或验收通过结论。
