## 1. 本轮范围

本轮实现 CI1302 经 STM32 接入方案所需的服务端保护，并补齐单机语音调度、重复请求处理、调用量限制、短回复缓存、数据保留及运营状态展示。保留现有 STM32 负载控制及 C3 在线音频链路。

本记录仅包含本轮实际执行的软件检查。未接入 CI1302 实物，未烧录设备，未操作样机负载，未采集或播放声音，未调用收费 ASR、LLM、TTS 服务，未部署云服务器。

## 3. 已覆盖的软件行为

### 3.1 调度、取消与请求重试

- 同设备任务按顺序处理；不同设备利用空闲执行槽位。
- 设备请求优先于等待中的研发批量任务，但不改变同设备已入队消息的先后顺序。
- 队列长度、同设备等待数量及等待时间受限；满载、过期及取消的等待任务不进入实际执行。
- 执行中任务取消后，在实际调用结束前继续占用槽位；超时后不能提交迟到的设备动作。
- 相同请求编号及相同内容共享结果；编号冲突被拒绝；失败可重试；大音频响应仅共享在途请求。
- 缓存中的直接控制动作再次返回前检查设备控制版本和有效期。普通对话不因本地控制变化而失去可复用结果。

### 3.2 本地控制与安全确认

- 本地有效操作使此前在线控制失效，包括设备状态未改变的重复关闭操作。
- 心跳及模式列表顺序变化不作为新的控制动作。
- 部分状态上报保留未上报的其他负载状态。
- 安全规则拒绝的结果不包含可执行动作；需要确认的首次响应不提前下发动作。
- 确认操作重新校验设备控制版本、期限与故障条件；旧确认及已消费确认不可重复执行。
- 本地事件要求事件编号与支持的来源，同编号不同内容被拒绝。

### 3.3 存储、限额与缓存

- 并发文件事务保留全部更新；文件不存在时的读取不覆盖后续新写入内容。
- 每日真实调用次数在调用前原子预留，重新加载后保留计数；估算费用阈值与次数限制可阻止后续调用。
- 短回复缓存受条数、字节及期限限制，返回数据相互独立。
- 文本保留同时遵守时间与数量上限。
- 正式环境设备凭据拒绝缺失、过短、共享及身份不匹配的情况。

### 3.4 既有语音与知识库回归

覆盖多轮上下文、会话隔离及重置、失败轮次处理、唤醒后的连续会话、常用命令和精确 FAQ 分流、知识库保守回答、单独 ASR/LLM 测试参数，以及已有音频数据和历史记录相关用例。服务商及设备动作由测试替身提供，不据此评价真实语音识别率、回答准确率或扬声器效果。

### 3.5 运营页面

使用构建产物和固定测试数据检查“系统状态”页面，验证五个调度环节、调用量、估算费用、保留策略、手动刷新和清理异常提示。桌面及手机宽度均无页面横向溢出，未出现浏览器脚本错误或非预期 API 请求。

页面请求全部由测试脚本拦截，未访问实际 API、MQTT、设备代理或 AI 服务。页面截图中的调用量、费用和维护异常均为测试数据，不属于实际运营记录。

截图由脚本生成于项目 `.artifacts/runtime-status-desktop.png` 和 `.artifacts/runtime-status-mobile.png`，不作为生产运行证明。

## 4. 数据与测试隔离

链路测试替换外部模型服务与硬件动作。持久化测试在 D 盘独立临时目录中执行真实文件读写，结束后清理对应目录，不使用项目现有运行数据。页面测试仅启动本地静态服务和无界面浏览器，完成后关闭。

## 5. 尚未验证的边界

1. **CI1302 接入。** 实际厂商串口码、STM32 接口、供电电平、唤醒与固定命令流程须取得模块后联调。
2. **设备最终仲裁。** 当前 `LOCAL_CONTROL` 是服务端准备好的入口，现有固件尚未上报该事件。STM32 → C3 的来源事件、话语关联编号及设备控制序号扩展尚待实现。服务端无法在收到事件前感知本地新动作，不能消除全部网络延迟冲突。
3. **声学表现。** 双麦、播放回声、在线离线重复唤醒、真实连续对话和断网提示未在本轮测试。
4. **容量与持久层。** 当前队列、缓存和 JSON 事务针对单进程，不提供跨进程调度及数据库事务；未形成 10 万台设备规模或任意并发数量的容量结论。生产持久层迁移和压力测试另行执行。
5. **计费。** 费用为已配置单价下的估算，未对账服务商账单。未配置单价、失败收费及在途调用可能导致偏差，估算费用阈值不是账单硬封顶。
6. **云端接入。** HTTPS、员工认证、设备独立密钥下发、MQTT 主题权限及正式部署仍需完整联调。通过当前软件检查不等于已满足公网生产上线条件。

## 6. 后续顺序

先确认 CI1302 工程和 STM32 预留接口，再验证本地固定命令；随后实现设备协同事件与控制序号扩展，验证本地关闭优先、同一句不重复执行、断网可控及恢复联网不重放旧动作。最后开展真实音频、服务商限额和目标部署环境的容量验证。
