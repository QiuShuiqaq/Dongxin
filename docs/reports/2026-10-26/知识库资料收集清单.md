# 东信智能浴霸项目知识库资料收集清单

日期：2026年10月26日

下一阶段，我们需要整理产品和售后知识，让设备能依据正式资料回答使用、安装、故障及售后问题。请先提供以下已有文件，无需重新编写整套资料，可以分批补充。

| 需要的资料 | 主要内容 | 用于回答的问题 |
| --- | --- | --- |
| 产品说明书、功能说明 | 型号、功能、操作方法、功能限制及注意事项 | “怎么开暖风？”“能不能设定温度？” |
| 安装与使用资料 | 安装条件、接线要求、首次使用、配网说明；有安装图可一并提供 | “安装需要注意什么？”“怎么连接网络？” |
| 清洁、保养和维护资料 | 清洁方法、维护周期、允许用户自行处理的范围 | “怎么清洁？”“哪些地方不能自己拆？” |
| 故障码与常见异常 | 故障码含义、可能原因、排查步骤、必须停用或报修的情形 | “显示这个故障码怎么办？”“不出热风怎么处理？” |
| 售后与保修规则 | 保修期限、保修范围、收费情形、报修渠道、用户需要提供的信息 | “保修多久？”“坏了找谁？” |
| 企业专业知识、常见问答和售后案例 | 产品相关专业解释、客服已有答复、典型问题及最终处理办法 | 回答说明书以外的常见咨询和实际使用问题 |

## 提供方式

直接提供现有Word、PDF、Excel等文件即可；扫描件、图片也可先提供，但优先使用文字清晰、可复制的版本。不要求为本次项目重新排版。

每份资料尽量注明适用型号、版本或日期，并指定一位可以确认内容的联系人。旧版与新版都需保留时，请注明当前适用版本；尚未确定的内容直接标记“待确认”。

售后案例和聊天记录请先去掉姓名、手机号、地址等个人信息。涉及用电安全、拆机、保修和收费的答复，以确认后的正式资料为依据。

## 后续安排

我们收到资料后，先按产品和问题分类，整理知识库初稿；存在冲突、缺失或需要确认的内容集中列出，再由资料联系人确认。确认后开展知识问答测试，实际结果另行记录。

优先提供产品说明书、功能说明、故障码和售后规则；其他资料随后补齐。现阶段不把尚未收到的资料写成已入库，也不提前给出问答测试结论。
