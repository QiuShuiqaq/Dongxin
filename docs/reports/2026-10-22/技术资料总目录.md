## 3. 源码与工程

源码按仓库原目录维护，不在本轮另建分叉工程。完整文件索引见[工程与工具清单](工程与工具清单.csv)。

| 目录 | 内容 |
|---|---|
| `apps/api` | AI网关、语音、设备、知识库、主动沟通、账号及测试接口 |
| `packages/shared` | 设备、控制和服务协议Schema及共享类型 |
| `apps/development-console` | 本地产品研发中心 |
| `apps/operations-console` | 设备运营平台 |
| `apps/device-agent` | 本机构建、烧录、串口及任务代理 |
| `apps/mqtt-broker` | 本地MQTT及设备Topic认证 |
| `apps/miniapp` | 微信小程序原型 |
| `firmware` | ESP-IDF工程、C3联网音频及样机适配 |
| `stm32-firmware/axent-controller` | STM32原始与AC6维护工程 |
| `stm32-firmware/tools` | 主控构建、备份、烧录及恢复工具 |
| `scripts` | 检查工具与测试资料生成脚本 |
| `apps/web`、`apps/mcu-simulator` | 历史工作台、模拟和参考代码 |

设备密钥、`.env`、运行数据、依赖目录、构建产物和本机备份不并入公开源码清单。历史源代码可以保留，是否用于当前链路由执行基线确定。
