## 1. 使用规则

本文件用于管理尚未形成有效结论的输入、参数和验证任务。开放项未关闭前，不得在技术报告、验收记录或对外沟通中表述为“已完成”或“已通过”。

开放项按以下状态维护：

| 状态 | 定义 |
|---|---|
| 待输入 | 需要东信、器件厂商或项目负责人提供正式资料 |
| 待实现 | 设计输入已具备，软件或固件尚未完成 |
| 待验证 | 已设计或已实现，尚未取得对应测试证据 |
| 阻塞 | 缺少必要硬件、SDK、参数或安全测试条件，当前无法执行 |
| 已关闭 | 输入、实现和验证证据完整，已记录关闭依据 |
