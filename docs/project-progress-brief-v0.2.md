# 东信 AI 浴霸项目开发进度简报

**日期：2026年9月24日**  
**当前阶段：软件和开发板测试阶段，等待样板联调**

## 下一阶段需要准备的内容

为了进入下一阶段，我们目前主要等待以下内容：

1. 浴霸真实样板；
2. 企业专业知识数据；
3. 产品说明书、功能说明、安装维护资料；
4. 故障码和售后规则。

样板到位后，我们先验证ESP32-C3与浴霸各项功能的连接和控制；资料到位后，我们同步建立知识库，并进行问答测试。其他硬件细节可以在样板联调过程中根据实际情况确认。

## 一、本次项目已经完成的内容

我们已经完成了第一轮软件开发和基础测试，后台、AI服务和ESP32-C3开发板之间的基本流程已经打通。

目前已经完成：

- 确定ESP32-C3作为第一版主要控制芯片，ESP32-S3保留作为备用测试方案；
- 确定CI1302作为离线语音芯片，负责“小东小东”、固定语音命令和语音前端功能；
- 确定使用3颗PCF8574，为浴霸预留24路控制接口；
- 完成ESP32-C3联网、后台通信、命令处理和基础安全控制；
- 完成语音识别、大模型和语音合成的基本调用流程；
- 完成东信产品研发中心和东信设备运营平台的基础页面；
- 完成单项测试、批量测试和结果导出功能的开发；
- 完成立创ESP32-C3开发板实验页面，用于查看传感器、触摸、按键、屏幕和网络状态。

## 二、已经实际测试的内容

### ESP32-C3联网和后台通信

我们已经使用ESP32-C3开发板完成：

- 连接Wi-Fi和本地后台；
- 接收后台命令；
- 执行照明、弱暖、强暖等文本模拟命令；
- 将执行结果返回后台；
- 重启后避免重复执行同一条命令。

这说明开发板、后台和通信流程已经跑通。由于样板和真实负载还没有接入，目前不能把这项结果当作浴霸真实动作已经验收。

### 立创ESP32-C3开发板

我们已经给立创开发板烧录测试固件，并通过网页完成基础读取。最近一次测试中：

- 板载5个I²C器件全部有响应；
- 温度、湿度、姿态和电子罗盘均能返回数据；
- 触摸芯片、按键、屏幕和网络状态可以查看；
- 功放默认关闭，避免测试时突然播放声音。

这块开发板用于验证ESP32-C3和网页测试流程，不能代替最终浴霸样板验收。

### AI语音服务

我们已经确认：

- 语音识别可以把测试音频转换成文字；
- 大模型可以根据文字判断浴霸操作；
- 语音合成可以生成语音文件；
- 后台可以进入单项测试和批量测试。

目前还没有使用正式数据统计准确率，也没有在样板机上完成实际播放测试。
