# 东信浴霸 MCU 串口协议 V0.2

> 历史兼容文档：2026-09-14起，新样板采用ESP32-C3唯一业务主控，不再使用C3到独立浴霸MCU的控制链路。本协议及模拟器仅用于旧产品兼容、协议测试和理解AXENT旧帧，不是新样板实现输入。

## 1. 决策

本协议曾作为东信新主控板和ESP32联网控制板的早期实现基线，现已被C3单主控架构取代。

| 项目 | 固定方案 |
| --- | --- |
| 物理层 | 3.3V TTL UART |
| 参数 | 115200 baud、8 数据位、无校验、1 停止位、无流控 |
| C3 UART | UART1，TX=GPIO4，RX=GPIO5 |
| 连接 | C3 TX 接 MCU RX，C3 RX 接 MCU TX，两端 GND 共地 |
| 帧长度 | 固定 32 字节 |
| 字节序 | 多字节整数使用小端序 |
| ACK 目标 | MCU 正常情况下 200 ms 内响应 |

禁止把 5V 信号直接接入 ESP32-C3。连接已有主控板前必须用万用表或逻辑分析仪测量电平；5V TTL 增加双向电平转换，RS-485 增加 3.3V RS-485 收发器。

## 2. 通用帧

| 字节 | WiFi 到 MCU | MCU 到 WiFi |
| --- | --- | --- |
| Byte0 | `0x02` | `0x02` |
| Byte1 | `0xCF` | `0xCA` |
| Byte2 | 品类 `0x07` | 品类 `0x07` |
| Byte3 | 命令码 | ACK、状态或事件码 |
| Byte4-27 | 数据区 | 数据区 |
| Byte28 | 8 位序号 | 原样回显序号 |
| Byte29 | Byte2 至 Byte28 异或 | Byte2 至 Byte28 异或 |
| Byte30 | `0x0F` | `0x0B` |
| Byte31 | `0x04` | `0x04` |

序号由 C3 每次发送时递增，`0` 之后回到 `1`。MCU 在 5 秒内收到相同命令码和序号时不得重复执行，只返回上次 ACK。

## 3. 控制命令

| Byte3 | 功能 | Byte4 |
| --- | --- | --- |
| `0x00` | 查询全量状态 | `0x00` |
| `0x01` | 照明 | `0x00` 关，`0x01` 开 |
| `0x02` | 换气 | `0x00` 关，`0x01` 开 |
| `0x03` | 吹风 | `0x00` 关，`0x01` 开 |
| `0x04` | 取暖 | `0x00` 关，`0x01` 弱暖，`0x02` 强暖 |
| `0x05` | 摆风 | `0x00` 关，`0x01` 开 |
| `0x06` | 干燥/除湿 | `0x00` 关，`0x01` 开 |
| `0x07` | 设置目标温度 | `30` 至 `45` 摄氏度 |
| `0x08` | 待机 | 固定 `0x01` |
| `0x09` | 定时 | `0` 取消，`1` 至 `120` 分钟 |
| `0x0C` | 联网功能 | `0x00` 关，`0x01` 开 |

未定义命令或参数必须拒绝，不允许按默认动作执行。

## 4. ACK 帧

MCU 使用命令码 `0x7F` 返回执行结果：

| 字节 | 含义 |
| --- | --- |
| Byte4 | 原控制命令码 |
| Byte5 | 结果码 |
| Byte6 | MCU 当前执行值 |
| Byte28 | 原请求序号 |

结果码：

| 值 | 含义 |
| --- | --- |
| `0x00` | 成功 |
| `0x01` | 不支持的命令 |
| `0x02` | 参数非法 |
| `0x03` | 安全联锁拒绝 |
| `0x04` | MCU 忙 |
| `0x05` | 硬件故障 |

C3 等待 ACK 500 ms，超时后使用同一序号重发一次；总计 2 秒仍无有效 ACK，则向平台回传 `timeout`。收到拒绝或故障 ACK 不重试。成功 ACK 后，C3 立即使用新序号查询一次全量状态；只有查询响应通过校验后才向平台回传成功，避免把“MCU 已接收”误报为“设备状态已确认”。

## 5. 全量状态帧

MCU 使用命令码 `0x10` 主动或按查询返回全量状态：

| 字节 | 含义 |
| --- | --- |
| Byte4 | 电源：0 关，1 开 |
| Byte5 | 照明：0 关，1 开 |
| Byte6 | 取暖：0 关，1 弱暖，2 强暖 |
| Byte7 | 换气：0 关，1 开 |
| Byte8 | 吹风：0 关，1 开 |
| Byte9 | 摆风：0 关，1 开 |
| Byte10 | 干燥：0 关，1 开 |
| Byte11 | 目标温度，摄氏度 |
| Byte12-13 | 环境温度，摄氏度乘 100，`int16` |
| Byte14 | 湿度，0 至 100 |
| Byte15 | 人感：0 无人，1 有人 |
| Byte16-17 | 故障码，`uint16`，0 表示无故障 |
| Byte18-21 | 本次运行分钟数，`uint32` |
| Byte22-27 | 预留，必须填 0 |
| Byte28 | 查询响应回显序号；主动上报填 0 |

以下事件必须立即上报全量状态：物理遥控器操作、面板按键操作、传感器状态变化、故障变化、命令执行成功。C3 每 30 秒发送一次状态查询作为丢包兜底。

## 6. 安全职责

- 平台负责意图安全校验和高风险动作确认；
- C3 只接受结构化白名单动作，并校验帧与超时；
- MCU 对过温、电机故障、互斥负载等硬件安全拥有最终否决权；
- MCU 拒绝后，C3 不得自行覆盖或伪造成功状态；
- 平台只有收到 C3 的成功结果和 MCU 状态后才显示执行成功。
